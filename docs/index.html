Windows 安装

双击 BiliCrawler-Setup.exe，向导里保持 FFmpeg 组件勾选，装完自动生成桌面与开始菜单快捷方式。

首次运行若弹出 SmartScreen「Windows 已保护你的电脑」，点 更多信息 → 仍要运行。安装包未做代码签名，属于正常提示。

macOS 安装

打开 dmg，把 BiliCrawler 拖进 Applications。首次启动在「应用程序」里 右键 → 打开 → 再点打开。

若提示「已损坏，无法打开」，终端执行一次：

xattr -dr com.apple.quarantine /Applications/BiliCrawler.app

安装包已内置 FFmpeg，不需要再装任何东西。

Linux 安装

Debian / Ubuntu 用 deb：

sudo apt install ./bilicrawler_amd64.deb

其它发行版用免安装包，解压后直接跑：

tar -xzf BiliCrawler-linux-x86_64.tar.gz && cd BiliCrawler-*-linux-x86_64 && ./bilicrawler

FFmpeg 需自行安装：sudo apt install ffmpeg（也可以打开程序后按提示自动下载）。

注意：包基于 Ubuntu 22.04 构建，要求 glibc ≥ 2.35。Ubuntu 20.04、Debian 11 等老系统需自行编译。

下载太慢？线路说明与校验

GitHub 原始下载在国内经常连不上，或只有几十 KB/s。页面顶部的下载线路可以一键切换：

  • 加速（推荐）：经 ghfast.top 公益中转，国内实测约 1 MB/s，46 MB 的 dmg 约 45 秒
  • 官方原始：直连 GitHub，海外网络或已挂代理时更快

加速线路是第三方公益代理，不受本项目控制，也不对传输内容负责。文件本身带 SHA-256 校验值，下完核对一次，对不上就切回官方线路重下。

shasum -a 256 BiliCrawler-macos-arm64.dmg

Windows 用 certutil -hashfile 文件名 SHA256；Linux 用 sha256sum。

体积主要来自内置的 FFmpeg 二进制（Windows 约 100 MB，macOS 约 43 MB）。FFmpeg 是 B 站 DASH 分离流的硬依赖，没有它连 360P 都合不出来。

数据与配置放在哪
  • Windows：%LOCALAPPDATA%\BiliCrawler，默认下载到 D:\BiliDownloads（无 D 盘则用户目录）
  • macOS：~/Library/Application Support/BiliCrawler，默认下载到 ~/Downloads/BiliDownloads
  • Linux：~/.local/share/BiliCrawler，默认下载到 ~/Downloads/BiliDownloads

Cookie 只保存在本机，不会上传到任何服务器。

系统要求
  • Windows：Windows 10 / 11，64 位
  • macOS：macOS 11 Big Sur 及以上（Apple Silicon 或 Intel）
  • Linux：glibc ≥ 2.35（Ubuntu 22.04+ / Debian 12+ / Fedora 36+），x86_64 或 ARM64
