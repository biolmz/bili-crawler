## BiliCrawler v1.1.0 — 首个公开版本

Windows 桌面工具：采集 B 站**公开数据** + 下载**公开投稿视频**。

**先解析、再勾选、最后下载**——粘贴链接后先看到完整清单，确认无误才动手。

### 亮点

#### 两段式流程，不会下错东西

```
粘贴链接  →  解析链接  →  清单勾选  →  开始任务
                ↑
        多P、UP主投稿在这里全部展开
```

多数下载脚本是「粘贴即开下」——多P 教程会一口气拉几十个文件，已失效的条目静默失败。
本工具把**解析**和**下载**拆成两步：清单里逐条勾选，标红的失败条目自动跳过。

#### 下载

- 支持 **BV 号 / av 号 / 完整链接 / b23.tv 短链 / UP 主空间链接**，一行一个，可整段粘贴
- **多P 视频自动拆成 P1 / P2 / P3…**，逐条列出可单独勾选
- UP 主空间自动展开最近 60 个投稿
- 清晰度：最高画质 / 1080P / 720P / 480P / 360P，或**仅音频**
- 内置 FFmpeg 自动合并音视频，按标题命名
- 实时进度：百分比、已下载大小、速度、剩余时间

#### 采集（输出 JSON）

| 字段 | 内容 |
|---|---|
| `video` | 标题、UP主、时长、播放/点赞/投币/收藏/弹幕数、发布时间、简介、分P列表 |
| `comments` | 评论人、UID、内容、点赞数、时间；按热度翻页，可设条数上限 |
| `danmaku` | 全量弹幕：出现时间点、类型、字号、颜色、发送者、内容 |

#### 界面

- tkinter 标准库手写，**无第三方 GUI 依赖**，打包体积可控、启动不依赖额外运行时
- 适配 Windows 高 DPI（200% 缩放下不糊不乱）
- 运行日志独立窗口，可随时查看、清空
- Cookie 仅存本机 `%LOCALAPPDATA%\BiliCrawler`，不上传任何数据

### 安装

#### 安装包（推荐）

1. 下载 `BiliCrawler-1.1.0-Setup.exe`
2. 双击运行，向导里**保持「FFmpeg 音视频合并组件」勾选**
3. 默认装到 `D:\Program Files\BiliCrawler`（无 D 盘则退回 `Program Files`）
4. 自动生成桌面 / 开始菜单快捷方式

#### 绿色版

解压 `BiliCrawler-1.1.0-portable.zip`，双击 `BiliCrawler\BiliCrawler.exe`。
FFmpeg 已一并附带，无需额外配置。

#### 系统要求

Windows 10 / 11 64 位

### 快速上手

1. **粘贴地址** —— 一行一个，可整段粘贴
2. **点「解析链接」** —— 只读取公开元数据，**不会下载任何视频**
3. **勾选条目** —— 点每行最左边的 `☑ / ☐`，或用「全选 / 全不选 / 反选」
4. **设置任务** —— 任务模式、画质、保存目录
5. **点「开始任务」**

支持的地址写法：

| 写法 | 说明 |
|---|---|
| `BV1GJ411x7h7` | BV 号，最常用 |
| `av80433022` | 旧版 av 号 |
| `https://www.bilibili.com/video/BV...` | 完整链接，带 `?p=2` 会自动定位分P |
| `https://b23.tv/xxxxx` | 手机分享短链，自动跳转解析 |
| `https://space.bilibili.com/123456` | UP 主空间，自动拉取最近 60 个投稿 |

> **关于 Cookie（可选）**：不填也能用。填了之后评论采集、UP 主投稿、高码率视频会更稳定。
> 浏览器登录 B 站 → `F12` → `Application` → `Cookies` → 复制 `SESSDATA` → 界面点「Cookie 设置」粘贴。

### 技术要点

- **wbi 签名**自行实现：`nav` 取 img_key/sub_key → 按 `MIXIN_KEY_ENC_TAB` 重排取前 32 位 →
  `md5(sorted_query + mixin_key)`。拼接前必须剔除值里的 `!'()*`，否则签名对不上
- 弹幕接口返回**裸 deflate 流**（无 zlib 头），需 `zlib.decompress(data, -15)`
- B 站同一分辨率提供 `avc1`/`hev1`/`av01` 三种编码，yt-dlp 默认常挑到 **AV1**
  （体积小但大量播放器打不开）→ 已锁定优先 **H.264**
- B 站只提供 DASH 分离流，**FFmpeg 是硬依赖**（没有它连 360P 都下不了），因此内置进安装包
- 高 DPI：`GetDeviceCaps(hdc, 88)` 取 DPI，`SCALE = dpi/96`，所有像素尺寸统一换算

### 已知问题
